# ADDATTE--Smart-Productivity-Platform


Addatte is a full-stack smart productivity platform designed to help users manage tasks, improve focus, and track productivity efficiently.

Built with React, Spring Boot, and MySQL, the platform provides secure JWT-based authentication, intelligent task management, productivity analytics, and gamified study/work tracking features.

## Features
- Secure user authentication and authorization using JWT
- Smart task creation, management, and prioritization
- Productivity analytics dashboard
- Task completion tracking and streak monitoring
- Productivity scoring system
- StudyMate feature with leaderboard and activity tracking
- RESTful backend APIs
- Responsive modern frontend UI
- MySQL database integration
